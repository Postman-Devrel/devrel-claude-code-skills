# Target outlets for contributed content

Outlets grouped by editorial focus. When recommending outlets for a pitch, match the pitch angle to the outlet's audience and coverage focus.

## Tier 1 — broad tech audience

| Outlet | Focus | Contributed content? | Audience |
|--------|-------|---------------------|----------|
| TechCrunch | Startup/enterprise tech news | Guest posts via editorial pitch | CTOs, VPs Eng, founders |
| Forbes Technology Council | Business-facing tech opinion | Member bylines | C-suite, enterprise decision-makers |
| VentureBeat | AI and enterprise tech | Guest contributor program | Enterprise tech leaders, AI practitioners |
| ReadWrite (formerly ReadWriteWeb) | Developer tools, AI, emerging tech | Contributed articles accepted | Developers, tech enthusiasts, early adopters |

## Tier 2 — developer and practitioner audience

| Outlet | Focus | Contributed content? | Audience |
|--------|-------|---------------------|----------|
| The New Stack | Cloud native, DevOps, platform engineering | Active contributor program | Senior developers, platform engineers, DevOps |
| InfoQ | Software architecture, emerging practices | Editor-reviewed contributions | Senior/staff engineers, architects |
| SD Times | Software development news and trends | Guest columns accepted | Development managers, team leads |
| DZone | Developer tutorials and opinion | Open contributor platform | Mid-to-senior developers |

## Tier 3 — AI and security specialist

| Outlet | Focus | Contributed content? | Audience |
|--------|-------|---------------------|----------|
| The Register | Enterprise IT, security, infrastructure | Guest opinion pieces | IT ops, security teams, sysadmins |
| Dark Reading | Cybersecurity news and analysis | Guest contributors | CISOs, security engineers, AppSec teams |
| AI Business | Enterprise AI adoption | Contributed articles | AI/ML practitioners, enterprise AI leads |
| Towards Data Science (Medium) | Data science, ML, AI engineering | Open contributor platform | Data scientists, ML engineers, AI builders |

## Tier 4 — API and integration specialist

| Outlet | Focus | Contributed content? | Audience |
|--------|-------|---------------------|----------|
| ProgrammableWeb (archived but referenced) | API economy, integration | Historical reference | API developers, integration architects |
| Nordic APIs | API strategy and design | Blog contributor program | API architects, product managers |
| API Evangelist | API industry commentary | Guest posts via Kin Lane | API strategists, developer advocates |

## Matching guide

- **Enterprise security angle** → Forbes Tech Council, Dark Reading, The Register
- **Developer tooling / DX angle** → The New Stack, ReadWrite, DZone
- **AI strategy / enterprise adoption** → VentureBeat, Forbes Tech Council, AI Business
- **Architecture / best practices** → InfoQ, The New Stack, SD Times
- **Startup / emerging tech** → TechCrunch, ReadWrite, VentureBeat
- **API design and strategy** → The New Stack, Nordic APIs, InfoQ
